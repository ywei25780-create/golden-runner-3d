# 小黄快跑 · 3D

一路快跑，笑着出发。和爱笑的小黄一起跳过仙人掌、躲开飞鸟、收集金币。

**[点击直接游玩 →](https://ywei25780-create.github.io/golden-runner-3d/)**

进入时先选择「手机版」或「电脑版」。无需注册，最高分只保存在当前浏览器。

| 版本 | 跳跃 | 伏身 | 暂停 |
| --- | --- | --- | --- |
| 手机 | 轻触跳跃按钮 / 游戏画面 | 按住伏身按钮 | 右上角暂停 |
| 电脑 | 空格 / ↑ / W / 点击游戏画面 | 按住 ↓ / S | P / Esc / 暂停按钮 |

每枚金币 +10 分，每五枚金币激活一个一次性护盾。离开页面自动暂停；在菜单中可以切换版本。小黄剧场可以连续播放或定格欣赏角色的大笑动作。

手机版为大触控按钮和竖屏安排界面，也支持横屏；电脑版保留键盘提示和鼠标操作。手机采用较低像素比和阴影尺寸，待机以约 30 帧刷新，页面隐藏时停止渲染。游戏逻辑使用固定时间步进，跳跃支持落地前 120 毫秒输入缓冲。

## 本地运行与修改

需要 Node.js 20+。安装依赖后运行测试和构建：

```sh
npm ci
npm test
npm run build
python -m http.server 8080 --directory docs
```

打开 `http://localhost:8080`。修改 `src/` 后重新构建，提交更新的 `docs/` 即可更新网站。

## GitHub Pages

发布目录为 `main` 分支的 `/docs`，已包含 `index.html` 和 `.nojekyll`。所有运行资源使用相对路径，适用于仓库子路径。3D 模型单独加载，便于浏览器缓存。运行时无需第三方 CDN、账号或服务端。

## 项目结构

- `src/`：页面、输入逻辑、固定步进游戏逻辑、骨骼动作与回归测试。
- `assets/`：角色模型源资源。
- `docs/`：GitHub Pages 的构建结果。
- `build.cjs`：可复现的静态构建。

3D 渲染使用 Three.js；其 MIT 许可和版权声明保留在 `docs/THREE-LICENSE.txt`。角色造型及动作沿用本项目已有素材；未包含原始参考视频或视频截图。

当前交付为浏览器游戏，微信小游戏平台适配仍需单独进行。
